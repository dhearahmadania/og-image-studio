# 🖼️ OG Image & Social Card Studio

A fast, client-side social banner generator built with React, TypeScript, and Tailwind CSS. Create crisp 1200x630 Open Graph card images for your blog posts, projects, or social media previews instantly—no backend required.

![Tech Stack](https://img.shields.io/badge/stack-React%20%7C%20TypeScript%20%7C%20Tailwind%20v4-violet)

## ✨ Features

- 🎨 **Preset Layouts:** Choose between Minimal, Gradient Mesh, and Developer Showcase designs.
- 🎛️ **Live Customization:** Edit title, subtitle, author details, badges, and gradient accents with instant preview.
- 📸 **1-Click High-Res Export:** Download pixel-perfect 1200x630 PNG images directly in your browser.
- ⚡ **100% Client-Side:** Private, secure, and blazing fast.
